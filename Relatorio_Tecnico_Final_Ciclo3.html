🎯 2. Descrição da Solução Desenvolvida

O MAGNED é uma plataforma acadêmica inteligente desenvolvida como Progressive Web App (PWA) que combina inteligência artificial local, reconhecimento facial biométrico, processamento de imagem via OCR e sincronização em nuvem para criar um ecossistema de aprendizado completo e inovador.

O sistema foi projetado para resolver dores reais do ecossistema acadêmico da UniEVANGÉLICA:

  • Dependência de internet: O motor de IA roda 100% no navegador, sem necessidade de APIs externas ou conexão
  • Fragmentação de ferramentas: Unifica AVA, Lyceum, calendário, flashcards, quizzes e Pomodoro em um único app
  • Segurança no login: Login biométrico facial dispensa senhas tradicionais
  • Acessibilidade: Instalável como app nativo em qualquer dispositivo

💡 Diferencial Técnico

Ao contrário de soluções que dependem de chaves de API (OpenAI, Gemini) — que sofrem com bloqueios CORS, custos recorrentes e quedas de conexão — o MAGNED processa toda a inteligência artificial diretamente no navegador do usuário. Isso resulta em latência zero, custo zero e funcionamento offline total.

3.3 Arquitetura do Sistema

Arquitetura Client-Centric Hybrid

3.4 Fluxo do Motor NLP Local

O coração do MAGNED é o arquivo magned_ai.js, uma classe JavaScript de ~600 linhas que implementa um motor cognitivo rule-based com NLP local:

Entrada do Usuário
       │
       ▼
┌──────────────┐    "matemática" → "matematica"
│ Normalização │    Lowercase + remoção de acentos (NFD)
└──────┬───────┘
       ▼
┌──────────────┐    22 categorias de intenção
│ Classificador│    Keyword matching contra ~150 palavras-chave
│  de Intents  │    Ex: "nota","média","boletim" → lyceum_grades
└──────┬───────┘
       ▼
┌──────────────┐    Mapa intent → função handler
│  Dispatcher  │    Ex: lyceum_grades → _lyceumGrades()
└──────┬───────┘
       ▼
┌──────────────┐    Acessa dados reais do aluno (notas, eventos,
│   Handler    │    nome, matéria, tutor) via this.S
│ Especializado│    Gera resposta dinâmica em Markdown
└──────┬───────┘
       ▼
┌──────────────┐
│  Memória     │    Buffer de 60 mensagens para contexto
│  da Sessão   │
└──────────────┘
ℹ️ Nota técnica: O motor classifica intenções como lyceum_grades, quiz, flashcard, pomodoro, motivacao, programacao, matematica, dados, ia_ml, entre outras 22 categorias. Cada handler gera conteúdo personalizado usando os dados reais do perfil acadêmico do aluno.

⚔️ 7. Dificuldades Enfrentadas e Decisões Técnicas

7.1 Desafios Técnicos

DesafioProblemaSolução Adotada
APIs de IA com CORS Chaves de API (OpenAI/Gemini) eram bloqueadas por CORS no frontend e expostas pelo GitHub Secret Scanning Criamos um motor NLP 100% local em JavaScript, eliminando qualquer dependência de API externa
Modelos de FaceID pesados Os modelos da face-api.js somam ~6MB e podem demorar para carregar em redes lentas Implementamos um sistema de fallback: se a câmera/modelo falhar, o login por email/senha funciona normalmente
OCR com precisão variável Tesseract.js tem dificuldade com fotos escuras, borradas ou com notação matemática complexa Adicionamos pré-processamento da imagem e orientação ao usuário sobre qualidade da foto
Service Worker e cache O SW falhava ao tentar cachear recursos externos (CDN) em localhost Usamos try/catch no addAll() para que falhas de cache de CDN não impeçam a instalação do SW
Sincronização offline/online Dados salvos offline poderiam conflitar com a versão do Firebase Adotamos estratégia "last-write-wins" com timestamps e prioridade para dados mais recentes
Performance em mobile A interface com muitas animações CSS ficava lenta em celulares antigos Otimizamos com will-change, transform ao invés de left/top, e reduzimos animações em viewports pequenas

7.2 Justificativa da Arquitetura Client-Centric

Optamos deliberadamente por processar tudo no navegador pelos seguintes motivos:

  • Custo zero: Sem servidor backend, sem custos recorrentes de API ou hosting
  • Privacidade: Dados acadêmicos e biométricos nunca saem do dispositivo do aluno
  • Latência zero: Respostas da IA são instantâneas, sem round-trip de rede
  • Resiliência: Funciona mesmo sem internet (offline-first)
  • Simplicidade: Um único diretório com 6 arquivos = app completo

💭 8. Reflexões sobre os Aprendizados do Processo

8.1 Aprendizados Técnicos

  • Arquitetura importa mais que framework: Provamos que é possível construir uma aplicação completa e moderna usando apenas HTML, CSS e JavaScript vanilla, sem React, Angular ou Vue. A decisão arquitetural (client-centric) foi mais impactante que qualquer escolha de framework.
  • PWA é subestimado: Com apenas dois arquivos extras (sw.js + manifest.json), transformamos uma página web em um app instalável que funciona offline. A barreira de entrada para PWA é surpreendentemente baixa.
  • IA não precisa ser generativa: O motor NLP local, embora rule-based, entrega uma experiência surpreendentemente rica e personalizada. Para domínios específicos (como o acadêmico), um sistema bem projetado de classificação de intenções supera a necessidade de um LLM genérico.
  • Biometria é acessível: Bibliotecas como face-api.js democratizaram o acesso a reconhecimento facial, tornando viável implementar autenticação biométrica em um projeto acadêmico.

8.2 Aprendizados de Processo

  • Iteração progressiva: A abordagem de 3 ciclos (conceito → interface → funcionalidade completa) foi essencial. Cada ciclo construiu sobre o anterior sem descartar trabalho.
  • Divisão clara de responsabilidades: Definir áreas de atuação (IA, frontend, backend, PWA, testes) desde o início evitou conflitos e acelerou o desenvolvimento.
  • Git como espinha dorsal: O versionamento com Git permitiu trabalho paralelo e rastreabilidade de todas as mudanças.
  • Documentação contínua: Manter relatórios atualizados a cada ciclo facilitou enormemente a compilação do relatório final.

8.3 Melhorias Futuras

  • 🔄 IA Generativa Híbrida: Integrar uma API de LLM (como Gemini) como fallback quando há internet, mantendo o NLP local como engine primário
  • 📊 Dashboard de Analytics: Gráficos de evolução do desempenho ao longo do semestre
  • 🔔 Notificações Push: Alertas automáticos de provas e entregas próximas
  • 🤝 Modo Colaborativo: Sala de estudo compartilhada entre colegas
  • 📱 App Nativo: Versão React Native ou Flutter para acesso completo às APIs do sistema
  • 🧪 Banco de Questões Expandido: Integração com bancos de questões reais do AVA

✅ 11. Conclusão

O MAGNED representa a culminação de um semestre inteiro de aprendizado e desenvolvimento colaborativo. Partimos de um conceito — "e se pudéssemos criar um assistente acadêmico inteligente que funcionasse sem internet?" — e construímos uma plataforma completa que:

  • ✅ Funciona 100% no navegador — sem backend, sem custos, sem chaves de API
  • ✅ É instalável como app nativo — PWA com suporte offline total
  • ✅ Integra IA real — Motor NLP com 22 categorias de intenção e personalização por tutor
  • ✅ Implementa biometria facial — Login seguro via câmera
  • ✅ Processa imagens com OCR — Resolução de exercícios por foto
  • ✅ Sincroniza dados na nuvem — Firebase para portabilidade entre dispositivos

Mais do que um projeto acadêmico, o MAGNED é uma prova de conceito de que é possível construir tecnologia inovadora, acessível e de nível corporativo usando ferramentas web modernas e uma arquitetura inteligente.
