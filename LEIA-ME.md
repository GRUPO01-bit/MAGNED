# MAGNED — Entrega Final (Ciclo 3) · Grupo 01

## 📦 Conteúdo desta Entrega

### 📂 Aplicacao/
Todos os arquivos necessários para rodar a aplicação no navegador:
- `index.html` — Landing Page com Login Facial
- `app.html` — Aplicação principal (Chat IA, Hub, Calendário, etc.)
- `magned_ai.js` — Motor de IA NLP local (600 linhas, 22 intents)
- `manifest.json` — Configuração PWA
- `sw.js` — Service Worker para cache offline
- `magned-icon.png` — Ícone do app

**Como rodar:** Abra `index.html` no navegador (recomendado Chrome/Edge).

### 📂 Documentacao/
- `Relatorio_Tecnico_Final_Ciclo3.html` — **Relatório técnico completo** (principal)
- `Relatorio_Entrega_Ciclo3.pdf` — Relatório resumido em PDF
- `Relatorio_Entrega_Ciclo3.html` — Relatório resumido em HTML
- `Relatorio_Entrega_Ciclo3.md` — Relatório resumido em Markdown
- `screenshot_*.png` — Capturas de tela usadas no relatório
